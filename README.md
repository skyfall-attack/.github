# SKYFALL organization profile

This repository supplies the public profile for [skyfall-attack](https://github.com/skyfall-attack).

## Publish

1. Create or open the **public** repository `skyfall-attack/.github`.
2. Add the contents of this directory to its root. The profile must be located at `profile/README.md`, with its logos in `profile/assets/`.
3. Commit to `main`. The logo URLs refer to this branch.

GitHub displays `profile/README.md` on the organization’s Overview tab. This repository does not deploy or modify the GitHub Pages website.

For an existing clone of `skyfall-attack/.github`, copy `profile/` into that clone, review the changes, and commit and push using your usual Git workflow. The `profile/` directory is what appears on the organization profile; this root README is setup documentation for maintainers.

Reference: [GitHub’s organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
